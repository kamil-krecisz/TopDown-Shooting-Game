# 🧟 Top Down Shooter 2D

A top-down 2D zombie wave survival game made in Godot. Shoot zombies, get cash, buy upgrades, and try not to die.

---

📦 **[Download Desktop Build (GitHub Releases)](https://github.com/kamil-krecisz/TopDown-Shooting-Game/releases)**

---

### 🎮 How it works
You get dropped into the map and zombies start spawning in waves. Every zombie you take down gives you money, which you can use in the shop to buy temporary power-ups (like a 60-second speed boost) to help you survive the next wave.

---

### ⚙️ Features & Mechanics
* **Movement:** Standard WASD controls with a Shift key sprint.
* **Shop & Economy:** Earn cash per kill and spend it on timed upgrades.
* **Wave System:** Survive each horde to get a short 2-second breather before the next one hits.

---

### 🧠 Zombie AI
* Automatically tracks and follows the player.
* Attacks as soon as it gets close enough.
* Spawns in waves with small pauses in between.

---

### 🧰 Tech Stack
* **Engine:** Godot 4.7.1
* **Language:** GDScript
* **Art:** 2D pixel art
